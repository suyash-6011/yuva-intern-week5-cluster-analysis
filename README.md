Week 5 Task: Cluster Analysis and Market Segmentation Submission Summary

This project focuses on applying unsupervised machine learning techniques to perform robust market segmentation and uncover hidden behavioral patterns within the automotive industry. Utilizing a comprehensive automotive dataset containing vehicle specifications, customer demographics, pricing tiers, and geographical parameters, the workflow executes data preprocessing, feature standardization, and normalization to ensure optimal clustering performance.

To determine the optimal number of clusters, evaluation methods including the elbow method and silhouette scores were rigorously applied. K-means and hierarchical clustering algorithms were evaluated, successfully segmenting the customer base and vehicle specifications into distinct, meaningful market clusters. Cluster evaluation was validated using statistical metrics and visual plots, including scatter plots and dendrograms, providing deep clarity on market groupings.

The accompanying .docx report and GitHub repository include the full Python implementation scripts, data standardization pipelines, visualization charts, and strategic interpretations designed to empower targeted automotive marketing strategies and consumer behavior analysis.
